MaiSaveTool 是一个用于管理和处理舞萌 DX 存档的小工具。

平时将国服存档转为私服格式，或是将水鱼查分器的成绩合并到RinNET，往往需要手动比对 JSON 文件。为了快速完成这些处理，便开发了这个应用。

主要功能
格式转换与引继 读取国服导出的原始存档并转换为私服（SDEZ）兼容格式，同时支持两份存档之间的数据快速引继。

成绩与进度合并 支持拉取水鱼查分器的打歌数据，或直接合并两份本地私服存档。打歌记录按照达成率与 DX 分整条择优，收藏品、开门状态及地图进度自动合并，避免高分被旧记录覆盖。

平台对接（RinNET 与水鱼查分器） 内置浏览环境，登录 RinNET 后可自动提取 Token 与拦截 Blob 导出，并支持将处理后的存档直接上传回服务平台，水鱼查分器则支持 OAuth 授权一键拉取全部成绩。

本地数据调整 支持修改用户名、Rating、游玩次数、段位、装扮（头像、姓名框、称号）、KALEIDXSCOPE 解锁、全地图通关，以及单曲成绩（难度、达成率、Combo、Sync 等）。

NFC 卡号读取 支持 NFC 的手机贴近实体 Aime 或 AIC 卡即可直接读取 20 位 AccessCode，省去手动录入卡号的麻烦。

使用须知
本项目主要面向自建服测试与个人数据备份交流，请勿用于破坏公共排名或影响正常游戏环境。
