舞萌DX 存档工具箱 (MaiSaveTool)
一款专为 maimai DX (舞萌DX) 玩家设计的 Android 存档管理与转换工具。本工具主要用于处理国服/官方存档向 SDEZ 私服格式 的转换、合并及本地化修改。
核心功能
•
⚡ 存档转移 (Transfer):
◦
支持将国服/官方格式的 JSON (如   ReisaRating.json) 转换为私服标准导入格式。
◦
数据驱动: 所有元数据（ROM 版本、登录日期、游玩地点等）均从源文件直接提取，杜绝硬编码。
◦
AccessCode 绑定: 转换时可同步绑定新的通行证卡号。
•
🔄 存档合并 (Merge):
◦
支持“取优”合并算法：自动对比两个存档中的歌曲成绩，保留达成率（Achievement）最高记录。若达成率相同，则保留 DX 分数（Deluxscore）更高的记录。
◦
同步合并收藏品、地图进度及 KALEIDXSCOPE 状态。
•
🛠️ 深度修改 (Edit):
◦
基础数值: 修改用户名、游玩次数、Maimile 货币。
◦
版本管理: 自定义 ROM 版本及 Data 版本。
◦
装扮/装备: 精确修改背景 (Frame)、头像 (Icon)、姓名框 (Plate)、搭档 (Partner) 及称号的 ID。
◦
物品管理: 任意解锁或锁定指定 Kind 和 ID 的收藏品。
◦
进度控制: 快速通关/重置地图进度，控制 KALEIDXSCOPE 的门锁与钥匙状态。
◦
成绩修正: 精确调整单曲的达成率、DX 分数及 Combo/Sync 状态。
•
🌐 RinNET 集成:
◦
内置浏览器，支持在应用内直接访问 NaomiNet 仪表盘。
◦
自动捕获: 自动拦截并下载网页生成的 Blob 存档文件，并实现即时载入。
◦
一键同步: 转换后的存档可直接同步至工作目录，方便快速上传。
技术特点
•
严格 Schema 对齐:
◦
userMusicDetailList 严格限制为 9 个必填字段，彻底解决因字段多余导致的服务器 400 错误。
◦
适配 SDEZ 严苛的字段命名规范（如 friend_regist_skip 下划线命名、totalRestLife 大写校对）。
•
智能 Rating 处理:
◦
在执行转移或合并操作时，程序会自动将所有 Rating 相关数值重置为 0。
◦
原理: 私服服务器会在存档上传后根据成绩列表自动重新计算最准确的 Rating，手动填入数值可能导致数据不一致。
•
安全保护机制:
◦
操作锁定: 转换或合并任务完成后，程序会自动锁定修改功能并强制跳转至下载页，防止在未保存当前结果的情况下进行二次修改导致数据污染。
使用说明
1.
设置工作目录: 首次使用建议设置 SAF 工作目录，以便程序自动同步生成的 JSON 文件。
2.
载入数据:
◦
如果是私服存档，直接在“信息”页点击“载入存档”。
◦
如果是国服转换，前往“转移”页，输入 私服使用的AccessCode（人话就是拿你在私服注册账户的卡号） 并选择源文件。
3.
执行操作: 根据需求在“修改”或“合并”页处理数据。
4.
导出结果: 在“下载”页重命名并保存，或直接上传至 RinNET。
